Implemented in v3.0

  • CSV ingestion and profiling.
  • Numeric median imputation + scaling.
  • Categorical mode imputation + one-hot encoding.
  • Classification: logistic regression, random forest, extra trees, gradient boosting, histogram gradient boosting, decision tree and k-NN.
  • Regression: ridge, random forest, extra trees, gradient boosting, histogram gradient boosting, decision tree and k-NN.
  • Random stratified and chronological holdout.
  • Classification and regression metrics.
  • Permutation feature importance.
  • Prediction API and local joblib model artifacts.

Limitations & roadmap

  • Shared-password access is enabled for hosted use; this is not multi-user isolation. Anyone with the password can access the same running workspace.
  • Dataset and live model registries are in memory and clear on restart.
  • Cross-validation, SHAP, neural networks, XGBoost, LightGBM, hyperparameter search and drift monitoring are not yet implemented.
  • Chronological split follows row order; it does not parse timestamps.
  • Permutation importance is not causal explanation.
  • Only load trusted joblib artifacts.
Use a strong, private APP_PASSWORD environment variable. This starter uses one shared password, not individual accounts or tenant isolation. Do not store sensitive personal or regulated data. Production use still requires stronger identity controls, persistent registry, logging, rate limits and a security review.
